# Privacy and security

+ **Nothing about your work leaves your computer.** The only thing the app ever sends over the internet is a request to its release page on GitHub for the number of the newest version - a little after it starts and every six hours while it is open, and only while **Check for updates when this computer is online** is ticked in Settings. When there is a newer version it downloads that version's installer from the same page. No runs, files, settings, names, GSTINs or figures go with either request. The one other download is the AI checker's, only when you press **Get the AI checker**: the Ollama runtime from Ollama's GitHub release page (checked against the fingerprint Ollama publishes) and the model from Ollama's model library - nothing of yours goes with it, and nothing at all is downloaded when Invoice Bridge already has the same AI on this computer. The release page is a public GitHub repository chosen by whoever builds and publishes your copy (`UA_UPDATE_REPO`); nothing is needed to read it, and the program carries no key for it. There are no uploads, no analytics, and no fonts or scripts fetched from elsewhere; the text-recognition models are part of the program.
+ **Updates cannot be faked.** Each release carries a small file naming the version and the fingerprint (SHA-256) of its installer, signed with the publisher's private key, which never leaves the publisher's own computer. The app checks that signature with the public key built into it, then checks the downloaded installer against the fingerprint. A file with the wrong signature is ignored, a download that does not match is thrown away, and nothing is installed until you press **Restart and update**.
+ **The AI checker works on your computer alone.** Its runtime listens on 127.0.0.1 only, on a port of its own, and dies with the app; the documents it reads never leave the computer. What it is asked to do is fixed in the program - copy a fixed set of fields - and nothing written on a document is taken as an instruction.
+ **It listens only on your own computer** (address 127.0.0.1, port 8000 to 8011). Other computers and phones on your network cannot reach it.
+ **It never logs in anywhere** and never stores a portal password.
+ **Files are only passed on when you ask**: *Share* hands a file to Windows' share window, *Open it in your email* opens your mail program with the letter, *Show in folder* opens File Explorer, *Open* shows a kept file in your browser, and downloads go to your Downloads folder. What happens next is up to you and those programs.
+ **The files behind Open, Save a copy, zip and Show in folder are found from the app's own records**, never from the address in a request, and kept file names are cleaned for Windows.
+ **The released program is checked before it is built**: the build refuses to go ahead if any spreadsheet, PDF or database other than the made-up sample data is inside it, so no one's real books can ship with it.
x **There are no user accounts or passwords.** Anyone who can use your Windows account can open the app and see everything in it, and any program running on your computer could talk to it while it runs.
x **The data is not encrypted.** The database, the kept copies of your files and the log are ordinary files in the data folder. Protect them as you protect your Tally data: with your Windows password and your disk encryption (BitLocker), and by backing them up.
x With update checks on, GitHub (owned by Microsoft) sees that your computer asked for the release file, and when - its internet address, as for any web page. Untick the setting and the app makes no connection at all; you can still update by running a newer `Install.exe`.
x The program's built-in technical pages (a description of its internal interface) are not switched off; if you open them in a browser, that browser fetches their page style from the internet. They are never linked from the app.

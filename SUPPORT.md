# Support

This is a volunteer, open-source project. Support is **best effort**: there is no
service-level agreement, no guaranteed response time, and no warranty (see the
licence).

- **Questions and bugs:** open a GitHub issue with what you did, what you expected,
  what happened, and the app's version (Settings shows it). Never attach real books,
  bills or screenshots with real names, GSTINs or amounts - reproduce it on the
  sample company in `SampleData/` instead.
- **Security problems:** not in an issue; see [SECURITY.md](SECURITY.md).
- **TallyPrime itself:** contact Tally Solutions; this project is not affiliated
  with them.
- **Your own deployment** (control plane, releases): [docs/configuration.md](docs/configuration.md).
